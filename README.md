# Setu Compliance

Setu is an India → EU industrial market-access control plane for manufacturers and exporters.

This repository is being populated from the validated Setu MVP build. It includes shipment-level market-access compilation, DPP, CBAM, FTA/origin, customs, evidence lineage, supplier evidence, SAP/MES/EMS integration adapters, and a 12-week steel pilot plan.

The complete README and implementation files follow in subsequent commits.
