# EuroSetu differentiated MVP

The market-access compiler treats the export transaction as the decision object and evaluates 15 rule families: CBAM, ESPR, DPP, REACH, origin, customs, FTA, buyer requirements, GPP, EPD, certification, sanctions, carbon, packaging and documentation.

It retains DPP, CBAM and export-package outputs and adds transaction economics: gross margin, CBAM exposure, FTA tariff saving, compliance cost, expected landed margin, FTA utilisation and value unlocked by remediation.

India-side adapter contracts now cover SAP, Oracle, Tally, MES, SCADA/EMS, LIMS, GST, DGFT/CoO, ICEGATE, verifier/lab and logistics. These are integration contracts only; no live government connectivity is claimed.

Evidence is modeled as claim → method → data → source → verifier → signed result. Supplier identities demonstrate verify-once/permission-share-many evidence reuse. Operational order-book rows remain explicitly synthetic until private enterprise data is connected.
