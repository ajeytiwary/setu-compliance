# Pilot recruitment: 10–25 real EU-bound steel shipments

## Ideal first design partner
An Indian steel/iron manufacturer, processor or merchant exporter with recurring EU shipments, an existing CBAM spreadsheet/document process, and enough operational autonomy to approve a bounded 10–25-shipment data extract without an enterprise transformation project.

Prefer an exporter that feels the pain but does not already have a mature SAP GTS + sustainability stack. MSME/medium exporters and foundry/re-roller clusters are attractive because current reporting indicates thousands of direct/indirect EU-exposed firms and material data-collection burden.

## Offer
**48-hour Market-Access Diagnostic**
Customer provides 10–25 shipment rows and the documents already sent to its EU buyer/importer. No SAP credentials, no write access, no production integration.

EuroSetu returns:
1. evidence completeness and blocker queue;
2. € order value affected by each blocker;
3. source/rule/evidence lineage for in-scope checks;
4. remediation priority by value unlocked;
5. a blind comparison against the customer's eventual broker/declarant/verifier outcome.

## Recruitment channels
1. Indian Steel Association: request introductions to member export/compliance teams.
2. Kolhapur foundry ecosystem: target direct/indirect EU exporters already receiving carbon-data requests.
3. Chhattisgarh steel re-rollers: target firms shipping directly or through merchant exporters.
4. Existing CBAM consultants/verifiers/customs brokers: offer EuroSetu as the evidence/decision layer rather than competing for legal sign-off.
5. EU importers buying Indian HRC/steel: recruit from the demand side when the exporter is reluctant; the importer has direct incentive to improve supplier evidence.

## Qualification questions
- Do you have 10–25 EU-bound 2026 shipments we can analyse?
- Which EU buyer/importer or broker receives your CBAM data?
- Are the CN codes, tonnes, invoice value and origin available in one export?
- Do you already have installation/operator emissions data or an EU CBAM workbook?
- What evidence was requested back or rejected?
- Who owns the decision to release a bounded anonymised extract?
- Can the eventual external acceptance/remediation outcome be shared back for blind validation?

## Commercial structure
Phase 0 discovery: 30 minutes, no data.
Phase 1 diagnostic: fixed scope, 10–25 shipments, CSV/document upload only.
Phase 2 shadow pilot: repeat on live shipments while existing process remains authoritative.
Phase 3 integration: only after diagnostic value is demonstrated.

Do not ask for SAP/MES/EMS access in the first sales call.
